# ByteStay

Reliable, intelligent and scalable automation tools and APIs.

- 🌐 Website: [bytestay.pt](https://bytestay.pt/)
- 🧩 APIs and products: [bytestay.pt/projects](https://bytestay.pt/projects.html)
- 🛠️ Open source: [bytestay.pt/open-source](https://bytestay.pt/open-source.html)

## Open source

MCP servers for AI agents (Claude, Cursor, VS Code), on PyPI and the official MCP registry:

- [distill-mcp](https://github.com/Bytestay/distill-mcp): clean Markdown from any web page.
- [unfold-mcp](https://github.com/Bytestay/unfold-mcp): PDF, DOCX, PPTX and XLSX to Markdown.
- [shipshape-mcp](https://github.com/Bytestay/shipshape-mcp): Dockerfile and Kubernetes lint.
- [specwise-mcp](https://github.com/Bytestay/specwise-mcp): OpenAPI validation and breaking-change diffs.

GitHub Actions for pull requests:

- [shipshape-action](https://github.com/Bytestay/shipshape-action): lint Dockerfiles and Kubernetes manifests.
- [specwise-action](https://github.com/Bytestay/specwise-action): find breaking changes in an OpenAPI spec.
- [cadence-action](https://github.com/Bytestay/cadence-action): explain and check cron schedules.

Apps and integrations:

- [ShivaMer](https://github.com/Bytestay/ShivaMer): Python code to Mermaid flowcharts.
- [ha-luz-indexada](https://github.com/Bytestay/ha-luz-indexada): indexed electricity prices in Portugal for Home Assistant.
