# bytestay/.github

Default community health files for every public repository in the [bytestay](https://github.com/bytestay)
organization. GitHub uses them for any repository that doesn't have its own:

- [CONTRIBUTING.md](CONTRIBUTING.md): how to report bugs, propose changes and open pull requests.
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md): Contributor Covenant 2.1.
- [SECURITY.md](SECURITY.md): how to report a vulnerability privately.
- [SUPPORT.md](SUPPORT.md): where to ask about our APIs.
- [Issue templates](.github/ISSUE_TEMPLATE) and the [pull request template](.github/pull_request_template.md).

What we build in the open: <https://bytestay.pt/open-source.html>.
